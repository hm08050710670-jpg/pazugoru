パズゴル　軽量基盤 v0.30・L30
============================

【今回遊べる内容】
STAGE 1「コラフ」の1戦です。
HP 1,200／2ターンに1回260ダメージ／草属性攻撃。
プレイヤーはHP 3,200。ピンクで回復、ほかの色は攻撃。
バンカービートル→ラフラビット→越谷ベビードラゴンは、この版にはまだ接続していません。

【iPhoneからGitHubへ】
1. このZIPを「ファイル」アプリへ保存し、ZIPを1回タップして展開します。
2. 展開したフォルダの中に index.html / game.js / audio.js / assets.js /
   style.css / course.json / stage01-korafu.json / bgm-shibajo.mp3 /
   course-riverside.webp / turf.webp / korafu-*.webp があることを確認します。
3. GitHubのpazugoruリポジトリで Upload files → choose your files を開き、
   今回のフォルダ内のファイルをすべて選択します。
   フォルダ名を1段挟まず、今のindex.htmlと同じ場所（リポジトリ直下）に置きます。
4. 全ファイルのアップロード完了を待ってから、Commit directly to main → Commit changes。
5. Pagesの公開処理後、ゲームを開き直します。
   画面下部の「軽量基盤 v0.30 · L30」が目印です。

重要：ZIPファイルそのものをGitHubへ置いてもゲームにはなりません。
重要：今回はindex.htmlだけの上書きでは動きません。JS・JSON・画像・MP3が必要です。
重要：古いbgm.wavやimg_01.webp等はこの版では使いません。残っていても問題ありません。
      他のページで使っている可能性があるため、勝手に削除する必要はありません。
重要：iPhone「ファイル」のHTMLプレビューは実行確認用ではありません。
      GitHub Pagesで公開したページをSafari等のブラウザで開いてください。

【音】
BGMは以前の「芝上のコンボ」60秒原本を128kbpsのMP3へ圧縮しています。
新しい曲や、フェード付きの試聴用音源に置き換えてはいません。
BGM初期音量14%、効果音100%（個々の音の元の設定に掛ける総音量）です。
BGMと効果音はメニュー内のスライダーで調整できます。上部にBGMボタンはありません。
読み込み直後にBGM再生を試みます。ブラウザが自動再生を制限する場合は最初の通常タップで開始します。
完全な無操作自動再生は保証できません。端末音量が0の場合は音が出ません。
ページを離れると一時停止し、復帰時に再開を試みます。制限時は次のタップで再開します。
音声の読み込み失敗時はメニュー内に「音を再読み込み」が表示されます。

【保存容量】
配信ファイル全体：約1.87MB。最大のファイルでも約0.96MBです。
index.htmlは約20KB、BGMは約0.96MB。
画像は全14枚（コラフ12ポーズ＋背景2枚）。表情名20状態の一部は同じ画像を共用しています。
画像を一枚へ統合して表情を失う方式にはしていません。
MP3は非可逆圧縮です。原本と全く同じ画素・音声データではありません。
キャラのWebPは透過・可逆圧縮で、画像の上下左右の端が透明であることを検査しています。

【今後のステージ追加用の構成】
index.html       画面の構造
style.css        見た目
assets.js        戦闘別の画像読込・解放・再試行
course.json      実装済み戦闘の一覧
stage01-korafu.json  コラフのHP・12ポーズ・表情別参照
korafu-*.webp    コラフだけの素材
course-riverside.webp / turf.webp  共通背景
bgm-shibajo.mp3  共通BGM
 audio.js       BGM・効果音の共通音声デバイスと音量管理
 game.js        入力・消去・攻撃・リアクション

スマホから一括で選びやすいよう、配布版はフォルダ階層を作らず同じ場所にまとめています。
キャラ別の管理はファイル名とステージ定義JSONで行います。
初回は現在の敵の画像だけ準備します。次の敵の先読みは必要なときだけ呼び出す構成です。
古い戦闘の画像は、アプリが持つ参照を解放します。ブラウザ内部のキャッシュやOSのメモリ解放時刻までは制御しません。
別の敵の正式追加には、素材だけでなく、その敵の属性別攻撃やクリア後遷移も追加します。
ステージ定義だけをコピーすれば新しい敵が完成するわけではありません。

【今回の検証範囲】
PC Chromium内で、同梱の実ファイルをテスト用の応答として読み込ませて検証しました。
公開GitHub PagesやiPhone実機に自動配置・接続して確認したものではありません。
・ゲーム33項目：起動、枠外ドラッグ、キャンセル、3/4/5個消し、10コンボ、回復、
  白いゴルフボール攻撃、葉っぱ攻撃、被弾、勝利、負け、リトライ、音量、ループ等。
・読込22項目：音声404後の再試行、画像不足後の再試行、現在の敵だけの読込、
  次の敵の任意先読み、旧画像参照の解放、タップ再生の制限を模擬した復帰等。
・320×568〜768×1024の画面寸法で、盤面が切れないことを確認。
・10戦闘ぶんのテスト用定義で、古い画像参照を貯め続けないことを確認。
  これは同じコラフ素材を用いた負荷試験です。完成した10ステージを収録した意味ではありません。
・元版の入力、マッチ判定、落下処理はコードの比較でも一致を確認。
・実機の音量感、Safari固有の入力・音声挙動、通信条件は公開後の最終確認が必要です。

【トラブル時】
「必要なファイルが読み込めない」：ZIPの全ファイルが同じ場所に置かれているか確認してください。
BGMだけ出ない：メニューの音量、端末の音量、最初のタップを確認し、必要なら音声を再読み込み。
表示が旧版：GitHubのindex.htmlが今回のL30か確認し、Pages公開処理後にページを更新してください。
